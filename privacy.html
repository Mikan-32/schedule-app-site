プライバシーポリシー

「スケジュール管理アプリ」（以下「本アプリ」）での利用者の情報の取り扱いについて説明します。

1. 取得する情報

  • 利用者が設定した連絡ツール（Discord など）に届いたメッセージの本文・画像と、その送信者名・チャンネル名
  • Google アカウントの認可情報（アクセストークン・リフレッシュトークン）

Google のデータについては、本アプリが作成したカレンダーとその予定へのアクセス（スコープ https://www.googleapis.com/auth/calendar.app.created）だけを求めます。利用者が自分で作成したカレンダーや予定、そのほかの Google アカウントのデータにはアクセスしません。

2. 利用目的

  • メッセージから予定を見つけ、本アプリの中で管理するため
  • 確定した予定を、本アプリが作成した Google カレンダーの専用カレンダーに追加・更新・削除するため

3. 保存と送信

メッセージ・予定・認可情報は、利用者の PC の中にだけ保存します。メッセージの解析は PC 上で動くローカル AI で行い、作者や第三者のサーバーには送信しません。外部との通信は、Google カレンダーへの予定の登録と、利用者が設定した連絡ツールとの通信に限られます。

4. 第三者への提供

取得した情報を第三者に提供・販売することはありません。広告にも使いません。

5. Google API から受け取った情報の取り扱い

本アプリによる Google API から受け取った情報の使用および他のアプリへの転送は、限定使用の要件を含む Google API サービスのユーザーデータに関するポリシーに準拠します。

6. 連携の解除とデータの削除

Google アカウントのサードパーティ製のアプリとサービスから、いつでも本アプリのアクセスを取り消せます。本アプリが PC に保存したデータは、本アプリのデータフォルダを削除すると消えます。

7. お問い合わせ

GitHub の Issues からご連絡ください。

8. 改定

内容を変更するときは、このページを更新します。
